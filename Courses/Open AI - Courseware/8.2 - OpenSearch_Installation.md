**OpenSearch Server**

1. Download OpenSearch zip file from the URL: <https://opensearch.org/downloads.html>
2. Extract the archive into a destination folder, example **C:\opensearch**
3. Set the following two environment variables
   1. **OPENSEARCH\_JAVA\_HOME** (value as C:\opensearch\jdk)
   2. **OPENSEARCH\_INITIAL\_ADMIN\_PASSWORD** (value as Opensearch#01)
4. Test the OpenSearch installation by running the following bat file at the Command Prompt
   1. C:\opensearch-2.18.0\**opensearch-windows-install.bat**
   2. Open a new command prompt and send requests to the server to verify that OpenSearch is running. (--insecure flag is required since TLS certificates are self-signed)

curl.exe -X GET https://localhost:9200 -u "admin:Opensearch#01" --insecure

* 1. Query the Plugins endpoint

curl.exe -X GET https://localhost:9200/\_cat/plugins?v -u "admin:Opensearch#01" --insecure

1. Shutdown the OpenSearch server by pressing Ctrl+C in Command Prompt / PowerShell and press Y to confirm.

Continue to step 6 if above two curl commands gave response successfully.

1. Start OpenSearch server by running the following batch file

C:\opensearch\bin\opensearch.bat

**COMMANDS TO WORK WITH INDICES**

**GET ALL INDICES**

curl https://localhost:9200/\_cat/indices?v -u "admin:Opensearch#01" --insecure

**GET CONTENTS OF INDEX named document**

curl -X POST https://localhost:9200/funfacts**/\_search** -u "admin:Opensearch#01" **--data "{ \"query\": { \"match\_all\": {} }}"** --insecure --header "Content-Type: application/json" > demo.json

**DELETE INDEX named funfacts**

curl -X DELETE https://localhost:9200/funfacts -u "admin:Opensearch#01" --insecure

**OpenSearch Dashboard**

1. Download OpenSearch zip file from the URL: <https://opensearch.org/downloads.html>

OR

Use the Direct link for a version 2.18.0: <https://artifacts.opensearch.org/releases/bundle/opensearch-dashboards/2.18.0/opensearch-dashboards-2.18.0-windows-x64.zip>

1. Extract the archive into a destination folder, example **C:\opensearch-dashboards-2.18.0**
2. Run the following in PowerShell if path-length-related error is encountered during extraction

Set-ItemProperty -Path HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem LongPathsEnabled -Type DWORD -Value 1 -Force

1. Run OpenSearch Dashboard from Command Prompt/PowerShell

C:\opensearch-dashboards-2.18.0\bin\opensearch-dashboards.bat

1. To stop OpenSearch Server and Dashboard, press Ctrl+C in Command Prompt / PowerShell and press Y to confirm termination OR close the Command Prompt / PowerShell window.
