# Simplified RACI Matrix

*For small teams: PM/BA, Developer(s), QA (optional dedicated role)*

## Roles

**PM/BA** — Project Manager / Business Analyst (often combined)

**DEV** — Developer(s) / Engineers

**QA** — Quality Assurance (may be shared by DEV)

**STAKE** — Business Stakeholders / Client

**Key:** R = Responsible, A = Accountable, C = Consulted, I = Informed

| **Activity** | **PM/BA** | **DEV** | **QA** | **STAKE** |
| --- | --- | --- | --- | --- |
| Requirements & PRD | R/A | C | I | C |
| User Stories & Wireframes | R/A | C | C | C |
| Estimation & Sprint Planning | R/A | R | C | I |
| Technical Requirement Doc | C | R/A | C | I |
| Architecture Design | C | R/A | I | I |
| Database & API Design | I | R/A | C | I |
| Sprint Execution & Review | A | R | C | I |
| Coding & Unit Tests | I | R/A | I | I |
| Code Review | I | R/A | C | I |
| CI/CD Setup | I | R/A | I | I |
| Testing | I | C | R/A | I |
| UAT Coordination | R/A | C | R | R |
| Production Release | A | R | C | I |
| Monitoring & Support | C | R/A | C | I |
| Documentation | C | R | C | I |
| Bug Fixes | A | R | C | I |
