Roles used:

* **PM** — Project Manager
* **BA** — Business Analyst / Product Owner
* **UX** — UI/UX Designer
* **ENG** — Developers / Engineers
* **ARCH** — Design/Solution/Cloud/Enterprise Architect
* **QA** — Quality Assurance / Testers
* **SEC** — Security Engineers
* **DEVOPS** — DevOps / Platform Engineering
* **DBA** — Database Administrator
* **STAKE** — Business Stakeholders
* **SUPPORT** — Support/Operations

**Key:**

* **R = Responsible** (does the work)
* **A = Accountable** (final decision / owns outcome)
* **C = Consulted** (provides input)
* **I = Informed** (kept updated)
